Flexbox

Esta es una propiedad de CSS que nos permite hacer que un contenedor sea mas flexible en cuanto al posicionamiento de sus elementos

Para iniciar el flexbox debemos escribir en nuestro contenedor la siguiente sintaxis:

Dirección y Distribución

Ya con nuestra flexbox creada, podemos dar una direccion al contenido de esa flexbox, como por ejemplo:

Row

El contenido de este contenedor se verá en fila (comportamiento por defecto).

Row-reverse

El contenido se verá en fila, pero en orden inverso (de derecha a izquierda).

Column

El contenido se verá en columna (apilado verticalmente).

Column-reverse

El contenido se verá en columna en orden inverso (de abajo hacia arriba).

Distribución (Justify Content)

Define cómo se distribuye el espacio entre los elementos en el eje principal.

Flex-start: Se alinea al inicio del contenedor

Flex-end: Se alinea al final del contenedor

Space-between: Espacio máximo entre elementos.

Space-around: Espacio igual alrededor de cada elemento.

Center: Elementos centrados en el eje principal.

Space-evenly: Espacio idéntico entre cualquier par de elementos y los bordes.

Alineación de Items (Align Items)

Define cómo se alinean los elementos en el eje secundario (vertical si es fila).

Flex-start: Alineación al inicio del contenedor.

Texto alineado al inicio junto a la imagen

Center: Alineación central vertical.

Texto alineado al centro junto a la imagen

Flex-end: Alineación al fondo del contenedor.

Flex Wrap

Determina si los elementos hijos se ven obligados a permanecer en una sola línea o si pueden saltar a nuevas líneas.

Nowrap: Los elementos se comprimen en una sola línea (comportamiento por defecto).

Wrap: Los elementos saltan a la siguiente línea si no caben.

Wrap-reverse: Los elementos saltan a la línea anterior (hacia arriba).

Alineación de Contenido (Align Content)

Esta propiedad solo funciona cuando hay múltiples líneas (flex-wrap: wrap).

Space-between: Distribuye las líneas de elementos con espacio máximo entre ellas.

Space-around: Distribuye las líneas de elementos con espacio igual alrededor de ellas.

Center: Junta todas las líneas en el centro del contenedor.

Flex-start: Distribuye las líneas de elementos al inicio del contenedor.

Flex-end: Distribuye las líneas de elementos al final del contenedor.

Stretch: Distribuye las líneas de elementos para que cubran todo el contenedor

Orden y Flexibilidad

Estas propiedades se aplican directamente a los hijos (flex-items) para controlar su comportamiento individual.

Order

Cambia el orden visual de los elementos sin alterar el HTML. Por defecto todos son 0. Aquí el primer ítem tiene order: 2.

1 (Order: 2)
2 (Order: 0)
3 (Order: 0)

Flex-grow

Define la capacidad de un ítem para crecer y ocupar el espacio sobrante.

Grow: 0
Grow: 1
Grow: 2

Flex-shrink

Define la capacidad de un ítem para encogerse cuando no hay espacio suficiente. El ítem rojo tiene shrink: 0 (no se encoge).
